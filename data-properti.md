## 5. Standar Aturan & Format Penyusunan Scene (Blueprint Google Flow)

Bagian ini adalah **aturan baku (standard operating procedure)** untuk menyusun file prompt adegan berikutnya (`adegan2.md` s/d `adegan7.md`). Semua file adegan **wajib** mengikuti struktur yang telah terbukti berhasil di `flow-scenes/adegan1.md`.

---

### 5.1. Struktur Header Dokumen Adegan
Setiap file adegan (`adeganX.md`) harus diawali dengan header berikut:
1. **Judul Adegan**: Nomor adegan, nama adegan, durasi total, setting lokasi, dan daftar karakter.
2. **Mode Google Flow**: `Ingredients to Video` (Multi-image Reference).
3. **Daftar Media yang Diunggah ke Google Flow**:
   - **Grup A (Frame Utama)**: Daftar file `sceneX.jpg` hasil generate yang disimpan di folder `generated properti/Adegan/Adegan (X)/`.
   - **Grup B (Foto Karakter Pendukung)**: Daftar file karakter `(1).jpg` / `(2).jpg` di `generated properti/Karakter/` yang dipakai untuk menjaga konsistensi wajah & gerak bibir.

---

### 5.2. Format Baku Per Scene
Setiap scene harus menggunakan format persis seperti di bawah ini, diapit oleh `#format-start` dan `#format-end`:

```markdown
---
Scene [Nomor]
- Durasi Video: [4 / 6 / 8 / 10] detik
- Dialog: [Nama Tokoh - nada/gaya]: "Teks dialog..." ATAU Tidak ada (SFX: ...)
- Foto Referensi untuk Image Prompt: [Daftar file foto mentah karakter & latar, tanpa path folder]
- Image Prompt: 
\`\`\`
[Deskripsi visual adegan 16:9, fotorealistis, pencahayaan, posisi karakter, referensi foto, Negative prompt]
\`\`\`
- Foto Referensi untuk Motion/Google Flow: scene[Nomor].jpg (Hasil Image Scene [Nomor]) + [Nama Karakter (1).jpg jika ada wajah/dialog]
- Motion Prompt: 
\`\`\`
[Deskripsi kamera, aksi karakter, ekspresi]
Audio: [Instruksi suara / Dialog Bahasa Indonesia / SFX]
Negative prompt: [Larangan gerakan, distorsi, dan larangan bahasa Inggris]
\`\`\`
```

---

### 5.3. Aturan Ketat Penulisan Prompt (Bahasa Indonesia)
Seluruh prompt (**Image Prompt** dan **Motion Prompt**) ditulis sepenuhnya dalam **Bahasa Indonesia** yang deskriptif, kaya detail visual, dan sinematik.

#### A. Aturan Image Prompt
1. **Bahasa**: Wajib ditulis dalam Bahasa Indonesia.
2. **Rasio**: Wajib selalu mencantumkan `Rasio: 16:9`.
3. **Gaya**: Fotorealistis lingkungan kampus USK, sudut dan lensa kamera (misal `lensa 35mm`, `lensa wide 24mm`), pencahayaan alami (`cahaya siang hari`, `pencahayaan ruangan alami`, dll.).
4. **Penyebutan Referensi**: Wajib menyebutkan instruksi foto referensi secara jelas di dalam prompt (misal: `Gunakan foto terlampir LATAR-03C.jpg sebagai referensi tata letak ruang kelas, dan Pak Doni (1).jpg untuk referensi wajah dan pakaian`).
5. **Negative Prompt Gambar**: Wajib ada di baris akhir blok kode: `Negative prompt: kartun, animasi, ilustrasi, render 3D, CGI, tangan cacat, jari berlebih, wajah terdistorsi, buram, teks salah eja, watermark.`

#### B. Aturan Motion Prompt & Kontrol Audio (Anti-Halusinasi)
Untuk memastikan video bergerak natural dan audio di Google Flow (Omniflash) tidak berhalusinasi menghasilkan kata-kata bahasa Inggris:

1. **Bahasa Prompt**: Deskripsi gerakan kamera, pergerakan karakter, dan instruksi audio ditulis dalam Bahasa Indonesia.
2. **Scene DENGAN Dialog**:
   - Cantumkan penanda vokal dan teks: `Audio / Dialog: [Nama Tokoh - nada suara, vokal Indonesia]: "..."`.
   - Wajib tambahkan kalimat: `Gerakan bibir sinkron alami dengan dialog Bahasa Indonesia (lipsync natural).`
   - Wajib ada di Negative prompt: `Negative prompt: suara bahasa Inggris, dialog bahasa asing, aksen asing, suara robotik, bibir tidak sinkron, distorsi wajah.`
3. **Scene TANPA Dialog (Hanya SFX / Ambience)**:
   - Jelaskan suara efek atau suasana ruang kelas secara spesifik (misal: dering telepon, detak jarum jam, hening canggung).
   - Wajib cantumkan penegasan tegas: `Sama sekali TIDAK ADA dialog, TIDAK ADA percakapan suara manusia, TIDAK ADA ucapan bahasa Inggris.`
   - Wajib ada di Negative prompt: `Negative prompt: dialog suara manusia, ucapan bahasa Inggris, suara percakapan, berbicara ke kamera, berteriak.`
4. **Negative Prompt Motion Wajib**:
   - Setiap blok Motion Prompt **wajib** menyertakan baris `Negative prompt:` di baris paling bawah.

---

### 5.4. Panduan Durasi Video per Klip
Gunakan hanya opsi durasi yang didukung Google Flow / Omniflash:
- **4 detik**: Untuk shot reaksi cepat, cutaway, atau transisi pendek (misal: reaksi mahasiswa, jam dinding, close-up kartu).
- **6 detik**: Untuk shot dialog pendek (1 kalimat sedang), establishing shot, atau aksi tunggal.
- **8 detik**: Untuk shot dialog dua arah, dialog panjang, atau *tracking shot* berjalan.
- **10 detik**: Untuk shot pidato/penjelasan panjang yang tidak terpotong.
